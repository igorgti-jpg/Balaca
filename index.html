Como a Lógica Funciona por Trás dos Panos

Compare o código que fizemos em Python com a implementação em JavaScript executada neste site:

Python (agendamento.py) 
def horario_disponivel(horario, horarios_ocupados):
    # Retorna True se NÃO estiver na lista
    return horario not in horarios_ocupados
JavaScript (Navegador) 
function horarioDisponivel(horario, horariosOcupados) {
    // Retorna true se a lista NÃO incluir o horário
    return !horariosOcupados.includes(horario);
}
